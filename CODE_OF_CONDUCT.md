# Code of conduct

This project welcomes everyone who wants to make generated output better, whatever their background or experience.

In issues, pull requests and discussions:

- Be kind and assume good faith. Critique the rule or the code, never the person.
- Back claims with examples. That is how this project works anyway.
- No harassment, insults, or sexual, discriminatory or violent language or imagery.
- Do not post other people's private information.

Maintainers may edit or remove contributions and block participants who do not follow this. Report problems privately to the maintainers through the contact listed on the repository's GitHub profile.

This text is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
